# 记忆压缩

仅在容量超限、预计超限或确需压缩时读取。生效 L2 全库最多 1,000 条，整个 `MEMORY.md` 最大 0.3 MB（300,000 字节）；两项均需满足。

对 `MEMORY.md` 同时考虑条内和条间压缩：条内精简描述，条间合并重复或重叠规则、遗忘已失效或不再有价值的内容，保留有效约束与来源。

- 精简条内描述，不必要的细节可以留在 L1；不要通过把多条规则塞进一个巨型 Rubric 来“达标”。
- 先处理重复、矛盾和确认过时的内容，优先修改已有规则，只合并同一适用范围内语义重叠的标准，保留必要例外和来源。
- 可以参考 ID 中的日期和使用次数，优先保留最新、最热的要求。新规则可能还没机会使用，低频场景可能只在少数任务中适用，缺少历史统计也不代表从未使用；不能仅凭少用或未知删除规则。
- 时间和热度辅助内容判断，不代替证据。纯精简、改格式或合并不刷新日期；合并沿用来源中最新的可靠日期，次数取最大值而非相加，避免重复累计，并在历史注明近似合并。

核验来源，在 `memory-history.md` 保留删除原文、合并去向和理由，按 [容量与统计](memory-capacity.md) 记录改号对应关系。整理后运行容量检查；仍无法安全达标时，新要求先留 L1，已有超限如实报告，不强行删除或宣称通过。
